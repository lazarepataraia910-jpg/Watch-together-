# Watch Together

ვიდეოს ერთად ყურების საიტი: ქმნი ოთახებს პაროლით, მეგობრები ეძებენ ოთახს სახელით და პაროლით შემოდიან. ვიდეო (YouTube ან პირდაპირი .mp4 ბმული) სინქრონულად იკვრება ყველასთვის — დაკვრა/პაუზა/გადახვევა და ჩატი რეალურ დროში.

## გაშვება

```bash
npm install
npm start
```

გახსენი [http://localhost:3000](http://localhost:3000).

## როგორ მუშაობს

- **რეგისტრაცია/შესვლა** — `public/login.html`, პაროლები ინახება დაჰეშილი (bcrypt).
- **ოთახის შექმნა** — სახელი + პაროლი + (არასავალდებულო) ვიდეოს ბმული. ოთახის შემქმნელი ავტომატურად ხდება მისი მფლობელი და ვიდეოს კონტროლერი.
- **ძებნა და შესვლა** — ყველა შესული მომხმარებელი ხედავს ოთახების სიას (სახელით საძებნი), მაგრამ შესასვლელად სჭირდება ოთახის პაროლი.
- **სინქრონული ყურება** — `server.js`-ში Socket.IO ავრცელებს დაკვრა/პაუზა/გადახვევის მოვლენებს ოთახის ყველა მონაწილეზე. მხოლოდ ოთახის მფლობელს შეუძლია ვიდეოს წყაროს შეცვლა.
- **ჩატი** — მარტივი რეალურ დროში ჩატი თითო ოთახისთვის.

## მონაცემები

მომხმარებლები და ოთახები ინახება `data/users.json` და `data/rooms.json` ფაილებში (ლოკალურად, JSON-ის სახით — არ საჭიროებს გარე ბაზას). აქტიური ოთახის მონაწილეები/ჩატი ინახება მხოლოდ სერვერის მეხსიერებაში და იშლება სერვერის გადატვირთვისას.

## შენიშვნა

ეს არის მარტივი, თვითკმარი (self-hosted) ვერსია. თუ გინდა საჯარო დომენზე გაშვება (მეგობრებმა ინტერნეტიდან რომ შემოვიდნენ), საჭირო იქნება ჰოსტინგი (მაგ. Render/Railway/VPS), რადგან საჭიროებს მუდმივად გაშვებულ Node.js სერვერს (არა სტატიკურ ჰოსტინგს).
